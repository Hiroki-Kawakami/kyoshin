# kyoshin

M5Stackに強震モニタを表示

## 強震モニタ

防災科学技術研究所によって提供されている、日本全国の今現在の揺れをリアルタイムに表示するWebサービスです。  
利用条件などは [防災科学技術研究所のホームページ](https://www.kyoshin.bosai.go.jp/kyoshin/docs/new_kyoshinmonitor.shtml)をご確認ください。

## 対応デバイス

- [M5Stack Core2](https://docs.m5stack.com/ja/core/core2)
- [M5Stack CoreS3-SE](https://docs.m5stack.com/ja/core/M5CoreS3%20SE)

M5Unifiedを使用しているため、320x240 LCDとPSRAMを搭載したM5Stack Coreシリーズであれば使用可能かと思います。(未検証)  
PSRAM非搭載のCoreシリーズで動作させるには[旧バージョン](https://github.com/Hiroki-Kawakami/kyoshin/tree/no_psram)を使用してください。

## 使い方

### Wi-Fi設定

初回起動時の設定画面から接続してください。  
設定画面のその他から再設定できます。

### マップ画面

画面をタップすることで表示されるメニューから各種設定ができます。  
設定画面の `画面表示` > `画面レイアウト` からレイアウトを変更できます。

- 自動(横) : 通常時はズーム(横)、予報がある場合に情報(横)に切り替わります。(デフォルト)
- ズーム(横) : 画像を横方向に引き伸ばして表示します。
- ズーム(縦) : 画面を90度回転し、画像を縦方向に引き伸ばして表示します。
- 情報(横) : 画像をアスペクト比を保って表示し、余白に予報の情報を表示します。

### スタンバイモード

通常時、しばらく操作していないとスタンバイモードに移行します。(デフォルト30秒)  
スタンバイモード時は画面が暗くなり、画像の更新頻度が10秒に1度になります。(予報のチェックは1秒ごとに行います)  
予報や警報を受信すると通常モードに復帰して通知を行います。  
スタンバイモードの設定は、設定画面の `画面表示` から変更できます。

### 夜間モード

夜の時間帯は夜間モードに移行します。(デフォルト23:00~7:00)  
夜間モード時は画面が消灯します。  
予報を受信しても通知しないようになります。  
警報は夜間モード中でも通知します。  
夜間モードの設定は、設定画面の `夜間モード` から変更できます。

### 通知音

設定画面の `通知音` から変更できます。  
`繰り返し` の設定により、以下のように通知音が鳴動するタイミングが変化します。

- あり : 予報・警報が出ている間はずっと通知音を繰り返し鳴らします。
- 情報更新時 : 予報・警報の情報が更新されたタイミングで通知音を鳴らします。
- なし : 予報・警報を受信した最初のタイミングでのみ通知音を鳴らします。
